# 安装说明

## 选哪个文件

| 文件 | 大小 | 何时用 |
|------|------|--------|
| **`fanqie-assistant-v0.1.0.user.js`** | **267 KB** | **默认推荐**。本 fork 完整版，含反封禁 6 层防线 + 设备池 + Pin + 控制面板。 |
| `fanqie-assistant-v0.0.6.user.js` | 490 KB | 上游原始全功能版。**仅当**你需要书架 / 搜索 / 下载 / 听书 / 评论这些本 fork 精简策略不包含的功能时用。 |

两个文件**不要同时装** —— 同时启用会重复注入。

## 安装步骤

1. 安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox）或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 用浏览器打开 `fanqie-assistant-v0.1.0.user.js`（脚本管理器会自动识别 `.user.js` 后缀）。
3. 脚本管理器弹出安装页 → 点 **安装**。
4. 访问任意 `https://fanqienovel.com/reader/<item_id>` 章节页。

## 首次启动行为

- 自动注册 3 个设备，间隔 0 s / 10 s / 30 s（防"批量注册"风控）。
- 同时激活 30 天 SVIP。
- 控制面板 ⚙️ 出现在右下角（点开可看状态 / 设备池 / Pin / 节流 / 日志）。

**首次访问章节会等 ~30 s 直到第 3 个设备注册完成**——这是设计如此，不算 bug。

## 控制面板

页面右下角 ⚙️ → 点开 Popover → 点 ⮮ 切换为侧栏模式。

### 状态区
- 当前设备 ID（后 6 位）
- 节流倒计时（实时）
- 池子容量 + 健康数

### 设备池
- 3 个槽位健康状态
- 手动切到指定槽
- dead 槽位"补新设备"按钮（24 h 冷却）
- ⚠ "重置整个池子"（最后手段，会让所有 3 个 device_id 失效）

### Pin 列表
- 已 Pin 的书 + 章节数 + 大小
- 单本删除

### 节流
- 启用开关
- 最小 / 最大延迟（秒）
- 重置节流计时

### 诊断日志
- 最近 30 条预览
- 复制全部 / 清空

## 阅读器顶栏 📌

打开任意章节后，章节标题旁会出现 `📌 Pin 此书` 按钮。点击后：
- 把当前已读章节升级为持久化缓存
- 后续翻页自动写入 Pin 范围
- 控制面板里可查看 / 删除

配额：≤ 50 本 / ≤ 5000 章。

## 失败恢复弹窗

设备切换 / 池子空了时弹出，5 选项：

| 选项 | 行为 |
|------|------|
| 立即重试 | 5 s 内重试当前请求 |
| 切换设备 | 手动切到下一个 healthy 槽位 |
| X 秒后自动重试 | 退避重试（10 / 30 / 60 / 120 s）|
| 查看诊断 | 折叠 / 展开诊断日志 |
| 放弃本次 | 关闭弹窗，下次失败仍会弹 |

诊断区 `<details>` 默认展开，可一键复制粘贴到 issue。

## 调试

按 `F12` 打开控制台 → 过滤 `fqa:` 前缀。所有日志都在这里：

| 前缀 | 模块 |
|------|------|
| `[fqa:main]` | 主流程 |
| `[fqa:pool]` | 设备池 |
| `[fqa:throttle]` | 节流 |
| `[fqa:cache]` | 缓存 |
| `[fqa:reader]` | 阅读器 |
| `[fqa:recovery]` | 恢复弹窗 |
| `[fqa:panel]` | 控制面板 |
| `[fqa:logger]` | 日志本身 |

### 手动重置设备池
控制面板 → 设备池 → "⚠ 重置整个池子"。会让所有 3 个 device_id 失效并重新注册。**慎用**。

### 手动清空 Pin
控制面板 → Pin 列表 → 单本删除。

或浏览器 DevTools → Application → IndexedDB → `fqa-cache` → Delete database。

### 手动清空日志
控制面板 → 诊断日志 → 清空。

## 已知限制

- **无法永远不被封**：服务端持续升级风控，本 fork 设计目标是"用几个月不被封"，不是"永远"。
- **下载到本地文件（TXT / EPUB）**：未实现。Pin 已覆盖"本地持久缓存"核心需求。
- **听书 / 书架 / 搜索 / 评论**：未包含（v0.1.0 精简策略）。需要的话用 `fanqie-assistant-v0.0.6.user.js`（全功能 fallback）。
- **未在真实 Tampermonkey 长周期压测**：1–2 h 连续阅读已验证，1–3 天长测需要用户报告。

## 出问题怎么办

1. **F12 → 过滤 `fqa:`** → 复制最后 30 行日志
2. 控制面板 → 诊断日志 → "复制全部" → 贴到 issue
3. **包括**：浏览器版本 + 脚本管理器版本 + 触发场景（打开哪本书第几章 + 操作）
4. [提 issue](https://github.com/qianbkk/fanqie-novel-bypass/issues/new)

## 卸载

Tampermonkey → 仪表盘 → 找到脚本 → 卸载。  
缓存（IndexedDB）和持久化配置（GM_setValue）**不会自动清**，需要在浏览器 DevTools 里手动清，或控制面板里清 Pin 列表。
